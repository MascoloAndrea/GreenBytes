# Green Bytes — UI/UX Design & Human-Computer Interaction Project

Welcome to the repository for **Green Bytes** (originally *GreenBites*), a mobile application concept designed to transform food waste reduction into a seamless, rewarding, and sustainable daily habit for off-site university students.

The landing page for this project is hosted via GitHub Pages at [mascoloandrea.github.io/GreenBytes/](https://mascoloandrea.github.io/GreenBytes/).

---

## 📱 Project Overview

Developed as part of the **Human-Computer Interaction (HCI)** course at **Politecnico di Milano (A.Y. 2025/2026)**, Green Bytes addresses the environmental and economic challenges of domestic food waste. The platform guides users through smart grocery planning, real-time pantry tracking, and zero-waste dynamic recipe generation.

### Key Features of the Concept:
- **Smart Grocery Planning & Pantry Management:** Helps students keep track of expiration dates and optimal food storage conditions.
- **Dynamic Recipe Recommendation:** Suggests creative, zero-waste recipes using ingredients already available in the user's kitchen.
- **Eco-Impact Dashboard:** Tracks the user's reduced ecological footprint over time to keep them motivated.
- **Community Hub:** Connects zero-waste enthusiasts to share tips, guidelines, and localized initiatives.

## 📂 Project Roadmap & Deliverables

This repository is strictly organized following the User-Centered Design lifecycle milestones (`C1` through `C6`):

- **[C1] Needfinding:** Contextual analysis, target audience interviews, and problem statement definition.
- **[C2] Refinement & Focus:** Persona drafting, task definition, and domain scoping.
- **[C3] Task, Storyboard & Prototypes:** Low-fidelity sketches, user flows, and wireframes.
- **[C4] Medium-Fidelity Prototype (MF):** First interactive mockups and initial flow verification.
- **[C5] Heuristic Evaluation:** Peer review and cross-evaluation audits to spot usability flaws.
- **[C6] Final Delivery & Usability Testing:** High-Fidelity Figma implementation, real-user usability testing execution, and iterative UI corrections.

The full comprehensive report is available directly on the landing page as [Presentazione Finale.pdf](Presentazione%20Finale.pdf).
